## Real-Time Pothole Detection using Deep Learning (CNN + YOLO)

**Published Research Paper | Final Year Project | 2024**
Sathyabama Institute of Science and Technology, Chennai

### Problem Statement
Potholes cause road accidents and vehicle damage. 
Manual inspection is slow and inefficient.

### Solution
A real-time pothole detection system using smartphone cameras, 
CNN and YOLO deep learning models.

### Tech Stack
- Python
- CNN (Convolutional Neural Network)
- YOLOv3
- OpenCV
- Deep Learning / Computer Vision

### Key Highlights
- Real-time detection using mobile device camera input
- Compared 10+ existing pothole detection methods
- YOLO outperforms traditional methods in speed and accuracy
- Designed to assist local authorities in road maintenance
